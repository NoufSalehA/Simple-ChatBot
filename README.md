# AI Chatbot 🧠🤓

A simple AI chatbot built with **Python** and **Streamlit**, using the **Groq API** to generate AI responses.

## Features

* 💬 Chat with an AI assistant
* ⚡ Fast AI responses using Groq
* 🧠 Keeps the conversation history
## Technologies

* Python
* Streamlit
* OpenAI Python Library
* Groq API
* python-dotenv
